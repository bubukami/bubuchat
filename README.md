# BubuChat - 超轻量级实时聊天

一个极简的聊天应用，无需注册、无需数据库，打开就能用！

## ✨ 功能特性

- ✅ 无需注册登录，输入昵称即可
- ✅ 自动生成用户ID
- ✅ 实时消息传输（WebSocket）
- ✅ 在线用户列表
- ✅ 输入状态提示
- ✅ 响应式设计
- ✅ 自定义头像
- ✅ 自定义背景
- ✅ 6种精美主题
- ✅ 表情支持

## 🚀 快速开始

### 本地运行

**后端**：
```bash
cd server
npm install
npm start
```

**前端**：
```bash
cd client
npm install
npm run dev
```

访问 http://localhost:5173

## 🌐 在线部署

### 最简单：Railway（免费，5分钟搞定）

1. 访问 https://railway.app/ 注册账号
2. 连接你的 GitHub 仓库
3. Railway 自动检测并部署
4. 完成！

详细教程请查看 [部署指南](DEPLOY.md)

### 其他部署方式

- **Render**: 免费部署，支持 WebSocket
- **自己的服务器**: 使用 Nginx + PM2
- **Docker**: 一键部署
- **Vercel + Railway**: 混合部署

查看 [完整部署指南](DEPLOY.md) 了解更多
